# Brand Image Formats

Reusable AI-image style systems for our channels. Paste the **Master Style
Prompt** first, then add your slide-specific layout using the template. Keep all
text inside a safe central margin so it isn't cropped by video motion/zoom.

---

## Declassified History (Informational / Investigative)

Theme: *"How the West Sabotaged African Independence"* — a serious,
documented, declassified-history brand (CIA / MI6 / FBI, 1904–2022).

### Master Style Prompt (always include this)

> Dark cinematic documentary style with full-bleed deep charcoal/black
> backgrounds (#0D0D0D), high-contrast oversized typography, and a serious,
> authoritative, investigative mood. Use a unified font family like Montserrat.
> Color palette: Gold titles (#C9A84C), Off-White body text (#F0EDE8), and deep
> Red accents (#E63946).

### Palette & Type

| Role                 | Value          |
|----------------------|----------------|
| Titles               | Gold `#C9A84C` |
| Body text            | Off-White `#F0EDE8` |
| Accents              | Deep Red `#E63946` |
| Background           | Charcoal/Black `#0D0D0D` |
| Font family          | Montserrat (unified) |
| Mood                 | Serious, authoritative, investigative |

### Reusable Template

Combine the Master Style Prompt with your specific layout:

```
[Master Style Prompt] + Layout: [describe layout]. Title: "[Your Title]".
Subtitle: "[Your Subtitle]". Content: [describe the text and stats to include].
```

### Usage Notes

- Always lead with the Master Style Prompt, then append the layout via the
  template.
- Recommended aspect ratio: 16:9 for long-form; keep text within the central
  ~90% safe area so slow zoom/pan motion never crops it.
- Reuse this framework to generate as many matching slides as needed.
